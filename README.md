ОПЕРАЦІЙНІ СИСТЕМИ РЕАЛЬНОГО ЧАСУ ТА 32 БІТНІ МК

Лабораторна робота №6: Широтно-імпульсна модуляція для управління силовими 
елементами на основі апаратних таймерів

Обладнання: STM32H743VIT6, CubeMX, STM32CubeIDE.

Мета: Ознайомитися з принципами роботи широтно-імпульсної модуляції (ШІМ) на
STM32F411, навчитися використовувати апаратні таймери для керування силовими елементами
та реалізувати програму з керуванням шириною імпульсу за допомогою кнопки.

Завдання до лабораторної роботи:

Варіант 5. Запрограмувати одночасну генерацію ШІМ на PD12, PD13, PD14, PD15 з різними частотами (1 
кГц, 2 кГц, 500 Гц, 5 кГц), кнопка PA0 керує duty cycle тільки PD12

💡 Загальний опис функціоналу

Програма демонструє використання апаратних таймерів для генерації сигналів широтно-імпульсної модуляції (ШІМ) з різними несучими частотами.
Оскільки генерація ШІМ відбувається виключно на апаратному рівні периферії, центральний процесор мікроконтролера залишається вільним
для виконання інших завдань (наприклад, обробки кнопок).

Логіка роботи алгоритму:
- Ініціалізація та налаштування частот: Чотири апаратні таймери (TIM2, TIM3, TIM4, TIM5) налаштовані на роботу в режимі генерації ШІМ на першому каналі (Channel 1).
Завдяки однаковому дільнику частоти (Prescaler = 63) та різним значенням регістрів періоду (ARR), таймери формують сигнали з частотами 1 кГц, 2 кГц, 500 Гц та 5 кГц відповідно.
Математично розрахунок частоти для кожного таймера описується формулою: $F_{PWM} = \frac{F_{TIM}}{(PSC + 1)(ARR + 1)}$.
- Стартовий стан: Під час запуску програми за допомогою макросу __HAL_TIM_SET_COMPARE для всіх чотирьох каналів встановлюється початковий коефіцієнт заповнення (Duty Cycle) на рівні 50%.
Це означає, що всі світлодіоди зі старту світяться вполовину своєї максимальної яскравості.
- Керування яскравістю: Головний цикл програми (while (1)) здійснює неблокуюче опитування кнопки, підключеної до піна PC13.
- Антибрязкіт та зміна параметрів: При фіксації натискання (логічна "1" на вході) програма використовує системний таймер HAL_GetTick() для відліку 200 мс,
що слугує програмним захистом від брязкоту контактів. Після цього коефіцієнт заповнення виключно для таймера TIM2 збільшується на 10%. Коли значення перевищує 100%, воно скидається до 0%.
Візуально це виглядає як ступінчасте збільшення яскравості першого світлодіода при кожному натисканні кнопки, після чого він гасне і цикл починається знову.



⚙️ Схема підключення

Усі світлодіоди підключаються за стандартною схемою: Пін мікроконтролера → Анод (довга ніжка) → Катод (коротка ніжка) → Резистор (220 Ом) → GND (Земля).

- LED 1: PA0.
- LED 2: PA5
- LED 3: PA6.
- LED 4: PD12.
  
- Кнопка: VDD → Кнопка → пін PC13.
